# DAYO 🎮
### 3D Endless Horror Survival Shooter

**Dayo** (meaning *Invader* or *Outsider*) is a 3D endless action/arcade shooter game developed using **Unity**.

## 📖 Game Description
The world has been invaded by dark entities that hunt humans and consume their brains. As a survivor, your mission is to defend your house, eliminate the invading creatures, and survive the night.

Don't let them get inside. Your survival depends on it.

## 🎯 Game Features
- 3D First-Person Shooter Gameplay
- Endless Enemy Waves
- House Defense and Survival
- Weapon Switching and Shooting
- Score System
- Random Health and Ammo Drops
- Increasing Difficulty

## 🎮 Controls

| Key | Action |
|---|---|
| W, A, S, D | Move |
| Shift | Sprint |
| Space | Jump |
| C | Crawl |
| 1, 2, 3 / Mouse Scroll | Switch Weapons |
| Left Mouse Button | Shoot |
| Right Mouse Button | Aim / Zoom |
| P | Pause |
